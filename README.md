# Студия «Глина» — сайт керамической студии

Статический сайт на HTML, CSS и JavaScript без сборки. Соответствует структуре ТЗ-26/2026: 10 страниц и 404.

## Страницы
- `index.html` — главная
- `classes.html` — форматы и калькулятор
- `schedule.html` — расписание на 14 дней
- `gift.html` — сертификаты и предпросмотр
- `gallery.html` — галерея работ
- `corporate.html` — корпоративам и PDF-презентация
- `first-wheel.html` — пять ошибок новичка и промокод
- `contacts.html` — форма и контакты
- `thanks.html` — подтверждение
- `privacy.html` — учебный шаблон политики
- `404.html` — страница ошибки

## Запуск
Откройте `index.html` в браузере. Для локального сервера можно выполнить в папке проекта `python -m http.server 8000`, затем открыть `http://localhost:8000`.

## Структура
- `css/style.css` — визуальный стиль и адаптивность.
- `js/main.js` — меню, калькулятор, расписание, сертификат, форма и галерея.
- `js/analytics.js` — единая точка событий.
- `js/form.js` — место подключения реального приёмника.
- `files/corporate-presentation.pdf` — презентация корпоративного формата.
- `docs/utm.csv` — шаблон реестра UTM-ссылок.
- `docs/events.md` — список событий аналитики.
- `docs/prompts.md` — журнал запросов к нейросети.

## Перед публикацией
1. Заменить демонстрационные контакты на подтверждённые.
2. Указать настоящий GA4 ID вместо `G-XXXXXXXXXX` и проверить согласие на аналитику.
3. Развернуть Apps Script Web App, подключить `js/form.js` и настроить серверную валидацию/дедупликацию.
4. Утвердить текст политики конфиденциальности.
5. Заменить иллюстративные макеты галереи на реальные фото работ с правами на использование.
6. Создать og-cover размером 1200×630 в JPEG/WebP и указать абсолютный URL в OG-метаданных.
7. Разместить сайт на Vercel и вписать реальный URL.
8. Проверить Lighthouse на опубликованном сайте. Реальные оценки не заявляются заранее.

## Аналитика и данные
В демонстрационном режиме заявки сохраняются в localStorage только этого браузера. Они не отправляются администратору и не попадают в Google Таблицу. Для реальной работы нужно подключить серверный обработчик. Идентификатор GA4 намеренно оставлен заглушкой.
